🔄 Detailed Workflow
1
Load Configuration
Read configuration.json with model paths, classes, thresholds, and colors
2
Prepare Dataset Structure
Create folders: yolo/, coco/, visualizations/, confident/, uncertain/
3
Load Input Images
Scan images/ folder for .jpg, .png files
4
Generate Augmentations (Optional)
If --augment flag: create rotate ±15°, noise, flip versions (5 total per image)
5
Object Detection (GroundingDINO)
Detect all classes with box_threshold and text_threshold filters
6
Segmentation (MobileSAM)
Generate precise masks for each detected object
7
Human Review (If --review)
• Auto-confident (≥0.80): skip to Step 8
• Low confidence (<0.80): show interactive viewer
• User clicks to remove, presses C/SPACE to accept
8
Organize by Confidence
Save to confident/ or uncertain/ folder based on review decision
9
Save Outputs
• YOLO format: .txt files with normalized coordinates
• COCO format: JSON with masks and metadata
• Visualizations: overlay images for verification
10
Print Summary
Statistics: images processed, annotations per class, output locations

✨ Key Features
🚀 CPU-Only Pipeline
No GPU required. GroundingDINO + MobileSAM optimized for CPU inference on standard hardware.
🎯 Multi-Class Detection
Detect multiple object classes simultaneously. Easy to configure in JSON. Color-coded visualization.
👁️ Human-in-the-Loop
Interactive review with click-to-remove. Auto-confidence sorting. Separate confident/uncertain folders.
📊 Dual Format Export
YOLO format for YOLOv8 training. COCO format with segmentation masks. Both immediately ready for ML.
🔄 Data Augmentation
Optional 5x expansion: rotate ±15°, add noise, horizontal flip. Automatic for all detected objects.
⚙️ Production Ready
Comprehensive error handling, logging, resource cleanup, keyboard interrupt support. Type-hinted codebase.
